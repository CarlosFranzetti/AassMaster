## 0. Open questions resolved
- LEVELS: `spacing:0` = whole wave spawns on ONE tick, relative offsets by pattern (cell = type w/h): line dx=i*(w+6); column dy spread over playfield, dx=0; v = v1 offsets (dx=ceil(i/2)*10, dy=+-ceil(i/2)*(h+5)); wave dx=i*(w+6), dy=sin(i*.9)*32; burst random y; stagger zigzag dy=+-(h/2+3), dx=i*(w+4); ring radius=max(24,n*(max(w,h)+4)/2pi), centre dx=r. `wave.offsets [[dx,dy]..]` overrides pattern. Members of a spacing-0 wave SHARE one phase/amp/vy/drift seed so sine/bounce/drift keep the formation rigid. y of each member clamped CEIL+4..FLOOR-4-h. spacing>0 = v1 behaviour (queue at tick+i*spacing, pattern offsets in y only).
- `from:'left'`: spawn x=-w-6-dx, heading +x (every behaviour mirrored: charge stopX, hover hx, drift, bounce), drawn flipX, despawn at x>W+40. `from:'top'|'bottom'`: spawn y=-h-6 (bottom: H+6), x=lerp(W*.25,W+32,wave.y), heading (-0.3,+-1) normalised; only straight/sine/drift honoured (other behaviours fall back to straight); despawn off the far edge. `side:'floor'` turret: y=FLOOR-h, scrolls left at stage.bg.speedNear. `side:'ceil'` = T.
- PIXEL boss mouth: weak point = `Sprites.meta(boss,frame).mouth` only when `.open` (frames 2,3,5); bullet/beam inside mouth rect = x1, anywhere else on `meta.hit` = x0.25. Fallback if meta missing: mouth {36,30,28,34}, hit {8,6,w-16,h-12}. Idle cycle alternates frames 0/1 closed 40f and 2 open 50f so a window always exists. Hitboxes everywhere = sprite pos + `meta(name,0).hit` (player: `meta('player',f).hit`, fallback 8x6 at (8,5)); enemy w/h from Levels only used for spawn layout.
- Units: all `speed`/`pxps`/fire.speed in px/s. Boss attack-dictionary `speed` also px/s; a value < 20 is read as px/frame with ONE console.warn (safety net for LEVELS round-2 numbers 1.8 / 4). Phase `interval` seconds, no heuristic.
- Charge (R6) = GAUGE frames after the charge starts, which is 21f after the press: tier1 at press+51, tier2 press+81, tier3 press+117. orb frames: 0-1 growth (21..51), 2 tier1, 3 tier2, 4/5 flicker every 4 ticks (tier3). Gun fire cd goes 7/8 -> 12 from tier1 (`shoot` variant 'wheeze'). Beams pierce, per-target tick every 6f: tier dmg 4/7/12 (=~8/16/30 over a typical boss pass), t3 also deletes ebul in its box; beam_t1 24x10, t2 40x16, t3 64x24, speed 9. Release below tier1 = nothing. All numbers live in one CFG object (tuning only).

## 6. Gameplay rules fixed here
Force: pu_force lv1..3 (then 1000 pts); front = blocks ebul, contact 2 dmg/6f, shoots `bullet_opt` forward (lv2+ diagonals); throw: flies +x 7px/f to P.x+110, holds, y-lerps .06, shoots forward (+back at lv2+); recall homes 6px/f, snaps front if it arrives from the right else rear (flipX, shoots back). Death loses Force, power-1, weapon type kept. Weapons: main = v1 patterns; spread 3/3/5/5 way, short range; wave 2/2/4/4 sine, pierce 2; laser = hitscan 3px beam 96..192px, tick/3f; power lv shared across types. Chain: window 90f, mult=min(8,1+floor(n/3)), break with n>=3 banks n*50*mult ("CHAIN 12 +2400"); graze <7px from core, once per bullet, +50 pts, +18f window. Rank 0..1 start .5: +.004*mult/kill, +.02/pickup, -.25/death. Recovery: if powerLv==0 && no Force after a death, guaranteed pu_force(if lost)/pu_power/pu_shield within 5s. Swallow: lunge hit with shield = shield lost + spat out; without = 70f gulp, >=10 taps = spat out (90f inv, power-1), else dead. Checkpoints: pass = `checkpoint` banner+sfx; game over with continues (3/run) shows 9s CONTINUE screen -> resume at max(last cp, midboss.t if died in it) or at boss warning if died to the boss; lives reset to 3, power reset, score kept, chain 0.
